A responsive personal portfolio for John Steven Tampos, a BSIT student and full-stack developer based in Cebu, Philippines. It highlights selected work, programming languages, experience, education, and contact details through a clean editorial interface.

## Mata Tech Skills Showcase Challenge

This project was built for the **Mata Tech Skills Showcase Challenge: IT & Operations (IT & Programming), Web Development Intern Challenge**. The goal is to deliver a visually clean, functional personal portfolio that demonstrates layout, responsiveness, and basic JavaScript interactivity.

## Challenge Coverage

| Requirement | Implementation |
| --- | --- |
| Home | Name, real profile picture, bio, and introductory hero |
| Projects | Eight project entries with descriptions, technologies, images, and links |
| Contact | Name, email, and message form with local validation and success feedback |
| Responsive design | Mobile navigation and layouts built with CSS Grid and Flexbox |
| Smooth navigation | Anchor navigation with smooth scrolling |
| Dark mode bonus | Persistent light/dark preference saved in the browser |
| Animation bonus | Scroll reveals, language-tile entrance motion, and focused hover states |

## Features

- Light and dark modes with a saved preference
- Real-photo hero and avatar profile treatment
- CV-based programming language section with labeled icons
- Accessible project image previews with keyboard controls
- Local contact-form success feedback without sending email
- Reduced-motion support for visitors who prefer it

## Technologies Used

- HTML5
- CSS3 with custom properties, Grid, Flexbox, and responsive media queries
- Vanilla JavaScript with the Intersection Observer API
- Google Fonts: Manrope
- Lucide icons and Devicon language icons

## Run Locally

No build step is required. Start a static server from the repository root:

```powershell
python -m http.server 8080
```

Then open `http://127.0.0.1:8080` in a browser.
