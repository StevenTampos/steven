A responsive personal portfolio for John Steven Tampos, a BSIT student and full-stack developer based in Cebu, Philippines. It highlights selected work, programming languages, experience, education, and contact details through a clean editorial interface.

## Features

- Light and dark modes with a saved preference
- Real-photo hero and avatar profile treatment
- Short entry sequence on reload, followed by scroll-triggered content reveals
- CV-based programming language section with labeled icons
- Accessible project image previews with keyboard controls
- Local contact-form success feedback without sending email
- Reduced-motion support for visitors who prefer it

## Technologies Used

- HTML5
- CSS3 with custom properties, Grid, Flexbox, and responsive media queries
- Vanilla JavaScript with the Intersection Observer API
- Google Fonts: Manrope
- Lucide icons and Devicon language icons

## Run Locally

No build step is required. Start a static server from the repository root:

```powershell
python -m http.server 8080
```

Then open `http://127.0.0.1:8080` in a browser.
